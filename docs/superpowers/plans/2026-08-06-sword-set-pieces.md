# Sword Set Pieces (`cleave` + `swordfall`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two sword set pieces — `cleave` (an energy-crescent diagonal slash) and `swordfall` (a literal blade descending from the sky) — taking the effect catalog from 449 names / 35 shapes to 491 / 37.

**Architecture:** Both are generated set pieces in the `vfx-engine`'s fourth registry layer (element-parameterised, size-less, with cycles), exactly like the existing `bolt` / `smite` / `rockfall` / `ring-of-fire`. The one new engine capability is `cycleMode`: `cleave`'s alternating flurry needs each cycle to *differ*, so its cycle count multiplies `frames` (with `loops: 1`) instead of multiplying `loops`. No new rendering mechanism is introduced — staging stays arithmetic inside a draw function.

**Tech Stack:** TypeScript, Canvas2D, `tsx` for headless scripts, biome, Vite. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-06-sword-set-pieces-design.md`

Never `--no-verify`. (This corrects the plan as originally written, which batched the sync into Task 4; the hook makes that impossible, and every prior vfx-engine plan in this repo synced per task.)
- Work happens on branch `vfx-sword-set-pieces` in **both** repos.
- **`./scripts/sync-vfx-engine.sh` is permission-denied inside a subagent** (it writes into the sibling aio-editor repo). A subagent that needs it must ask the controller to run it from the main session rather than hand-replicating the copy — the vendored files are generated, never hand-written.
- The canonical engine lives at `eoweb/src/vfx-engine/`. Ten files are parity-guarded by `npm run vfx:parity`.

In `scripts/vfx-registry-check.ts`, add the block below **after line 158**, where the script's existing `registry`, `index` and `shapes` locals are already built — reuse them rather than rebuilding.

The expectations are **restated here rather than read from `SET_PIECES`** — an assertion that sourced `cycleMode` from the engine would pass no matter which field the generator multiplied, which is exactly the silent failure this guards.

```ts
// cycleMode invariant. Asserted for shapes WITH the cycles axis only:
// ring-of-fire declares loops: 3 and no axis, so an unrestricted
// `loops === cycles` would fail on it.
//
// The mode a shape SHOULD use is restated here, not read from SET_PIECES —
// reading it back would make this tautological, and both modes yield the
// same total duration, so a mis-wired multiplier is otherwise invisible.
const FRAME_MODE_SHAPES = new Set<string>([]);
const CYCLE_BASE_FRAMES = 4;

const CYCLE_SHAPE_IDS = new Set(
  shapes.filter((s) => s.layer === 'setpiece' && s.hasCycles).map((s) => s.id),
);

for (const [name, def] of Object.entries(registry)) {
  const axes = index[name];
  if (!axes || axes.layer !== 'setpiece') continue;
  if (!CYCLE_SHAPE_IDS.has(axes.shapeId)) continue;
  const cycles = axes.cycles ?? 1;

  if (FRAME_MODE_SHAPES.has(axes.kind)) {
    assert(
      def.loops === 1,
      `${name}: frames-mode set piece must have loops 1, got ${def.loops}`,
    );
    assert(
      def.frames === CYCLE_BASE_FRAMES * cycles,
      `${name}: frames-mode set piece must have frames ${CYCLE_BASE_FRAMES * cycles}, got ${def.frames}`,
    );
  } else {
    assert(
      def.frames === CYCLE_BASE_FRAMES,
      `${name}: loop-mode set piece must have frames ${CYCLE_BASE_FRAMES}, got ${def.frames}`,
    );
    assert(
      def.loops === cycles,
      `${name}: loop-mode set piece must have loops ${cycles}, got ${def.loops}`,
    );
  }
}
```

Note there is **no** `decomposeVfxName` function — decomposition is `buildIndex(): Record<string, VfxAxes>`, and `VfxAxes` carries `{ layer, kind, combo?, element?, size?, cycles?, shapeId }`. Branching on `axes.layer === 'setpiece'` is also cleaner than prefix-matching the shape id. No new imports are needed; the script already imports everything used here.

```ts
type CycleMode = 'loop' | 'frames';

interface SetPieceConfig {
  frame: FrameGeometry;
  frames: number;
  loops: number;
  frameMs: number;
  /** Descents only. `ring-of-fire` is inherently sustained — a one-cycle ring
   *  of fire is not a thing anyone wants — so it keeps its fixed `loops` and
   *  offers no axis, exactly as combos offer no size. */
  hasCycles: boolean;
  /** How the `cycles` axis is applied.
   *  'loop'   — multiply `loops`; the same rasterised cycle repeats. No extra
   *             textures. Correct whenever every cycle looks identical.
   *  'frames' — multiply `frames`, keeping `loops: 1`, so every cycle is
   *             rasterised separately and CAN differ. Costs textures linearly
   *             in the cycle count; only use it where cycles must differ.
   *  Inert for shapes with `hasCycles: false`, exactly as `size` is inert for
   *  set pieces — they still declare it, for uniformity. */
  cycleMode: CycleMode;
}
```

In `src/vfx-engine/kinds.ts`, above the `KINDS` table:

```ts
// ---- cleave ---------------------------------------------------------------
// A weighted crescent, NOT a literal blade: at 44x44 internal quantised to
// four rungs a sword mid-swing resolves to a bright stick, so the weight comes
// from the leading edge being thicker and hotter than the tail. This is the
// deliberate difference from the `slash` matrix kind, which is one thin
// tapered stroke with no mass to it (drawSlash, unchanged).

/** Frames the registry allots to ONE cleave. `cycleMode: 'frames'` multiplies
 *  SET_PIECES.cleave.frames by the cycle count, so this is how a draw call
 *  recovers how many cleaves it is part of. Asserted equal to the registry's
 *  base frame count in scripts/vfx-registry-check.ts. */
export const CLEAVE_FRAMES_PER_CYCLE = 4;

const CLEAVE_RADIUS = 33;
const CLEAVE_SEGMENTS = 20;
const CLEAVE_START_ANGLE = -0.8 * Math.PI;
const CLEAVE_SPAN = 1.06 * Math.PI;
const CLEAVE_LEAD_WIDTH = 11;
const CLEAVE_TAIL_WIDTH = 1.5;
// Extent: CLEAVE_RADIUS + CLEAVE_LEAD_WIDTH / 2 = 38.5 of the square frame's
// 64 design-px half-budget.

/** Which cleave of the flurry `progress` falls in, and how far through it.
 *
 *  Cycle geometry is derived from the cycle INDEX arithmetically — never
 *  through indexFrac. indexFrac's own 2.399 constant aliased ring-of-fire's
 *  ten tongues into a 16.2 degree band while looking independent in source;
 *  that bug is not worth repeating for three values. */
function cleavePhase(
  def: VfxDef,
  progress: number,
): { t: number; mirror: boolean; rotate: number } {
  const count = Math.max(
    1,
    Math.round(def.frames / CLEAVE_FRAMES_PER_CYCLE),
  );
  const scaled = progress * count;
  // Math.min guards the progress === 1 endpoint. frameProgress samples frame
  // midpoints so it never actually reaches 1, but drawEffectAt is also called
  // directly by the aio-editor preview's scrubber.
  const index = Math.min(count - 1, Math.floor(scaled));
  return {
    t: scaled - index,
    // Cleave 2 is the mirror of cleave 1 — that is what makes the X.
    mirror: index % 2 === 1,
    // Cleave 3 comes in steeper rather than mirroring back onto cleave 1.
    rotate: index === 2 ? -0.2 * Math.PI : 0,
  };
}

/** Strokes one crescent: a band along CLEAVE_RADIUS from the sweep's start to
 *  its current leading edge, thickening and brightening toward that edge. */
function cleaveBand(
  ctx: CanvasRenderingContext2D,
  cx: number,
  cy: number,
  phase: { t: number; mirror: boolean; rotate: number },
  colour: string,
  widthScale: number,
  alphaScale: number,
): void {
  const lead = CLEAVE_START_ANGLE + phase.t * CLEAVE_SPAN;

  ctx.save();
  ctx.translate(cx, cy);
  if (phase.rotate !== 0) ctx.rotate(phase.rotate);
  if (phase.mirror) ctx.scale(-1, 1);
  ctx.translate(-cx, -cy);

  ctx.lineCap = 'round';
  ctx.strokeStyle = colour;
  for (let i = 0; i < CLEAVE_SEGMENTS; i++) {
    const f = i / CLEAVE_SEGMENTS;
    const a0 = CLEAVE_START_ANGLE + (lead - CLEAVE_START_ANGLE) * f;
    const a1 =
      CLEAVE_START_ANGLE +
      (lead - CLEAVE_START_ANGLE) * ((i + 1) / CLEAVE_SEGMENTS);
    ctx.lineWidth =
      (CLEAVE_TAIL_WIDTH + (CLEAVE_LEAD_WIDTH - CLEAVE_TAIL_WIDTH) * f) *
      widthScale;
    // Tail is faint, leading edge solid; the whole band fades as it completes.
    ctx.globalAlpha = (0.2 + 0.8 * f) * alphaScale * (1 - phase.t * 0.35);
    ctx.beginPath();
    ctx.arc(cx, cy, CLEAVE_RADIUS, a0, a1);
    ctx.stroke();
  }

  ctx.restore();
  // Restore canvas defaults — a combo layer may be drawn straight after this.
  ctx.lineWidth = 1;
  ctx.globalAlpha = 1;
}

function drawCleaveBehind(
  ctx: CanvasRenderingContext2D,
  progress: number,
  def: VfxDef,
  cx: number,
  cy: number,
): void {
  // Wider and dimmer than the front core, so the tail reads as passing BEHIND
  // the target rather than across it.
  cleaveBand(ctx, cx, cy, cleavePhase(def, progress), base(def), 1.6, 0.45);
}

function drawCleaveTint(
  ctx: CanvasRenderingContext2D,
  progress: number,
  def: VfxDef,
  cx: number,
  cy: number,
): void {
  // Additive bloom onto the target. Low alpha: the tint layer is composited
  // `add` regardless of def.additive, so anything heavy here blows out.
  cleaveBand(
    ctx,
    cx,
    cy,
    cleavePhase(def, progress),
    rung(def, RAMP_BASE + 1),
    2.1,
    0.3,
  );
}

function drawCleaveFront(
  ctx: CanvasRenderingContext2D,
  progress: number,
  def: VfxDef,
  cx: number,
  cy: number,
): void {
  const phase = cleavePhase(def, progress);
  cleaveBand(ctx, cx, cy, phase, rung(def, RAMP_BASE + 1), 1, 1);

  // Spark flash at maximum extension — the moment the edge bites. Confined to
  // the back half of each cleave so a flurry flashes once per cycle.
  if (phase.t > 0.5) {
    const lead = CLEAVE_START_ANGLE + phase.t * CLEAVE_SPAN;
    ctx.save();
    ctx.translate(cx, cy);
    if (phase.rotate !== 0) ctx.rotate(phase.rotate);
    if (phase.mirror) ctx.scale(-1, 1);
    ctx.translate(-cx, -cy);
    ctx.globalAlpha = 1 - (phase.t - 0.5) * 2;
    ctx.fillStyle = rung(def, RAMP_BASE + 2);
    ctx.beginPath();
    ctx.arc(
      cx + Math.cos(lead) * CLEAVE_RADIUS,
      cy + Math.sin(lead) * CLEAVE_RADIUS,
      4,
      0,
      Math.PI * 2,
    );
    ctx.fill();
    ctx.restore();
    ctx.globalAlpha = 1;
  }
}
```

```ts
/** Planted height above the ground point: tip at cy, pommel top at
 *  cy - SWORDFALL_TOTAL_HEIGHT. Asserted against TALL_FRAME.groundY in
 *  scripts/vfx-registry-check.ts. */
export const SWORDFALL_TOTAL_HEIGHT =
  SWORDFALL_BLADE_LEN +
  SWORDFALL_GUARD_H +
  SWORDFALL_GRIP_H +
  SWORDFALL_POMMEL_R * 2;

/** How far above the ground the tip starts. Larger than the headroom on
 *  purpose: on the first frame the hilt is above the frame edge and clips,
 *  which reads as the sword entering from off-screen. Every LATER frame is
 *  fully on-screen (see the extent assertion). */
const SWORDFALL_START_ABOVE = 150;
const SWORDFALL_LAND_PROGRESS = 0.5;

/** Tip offset above the ground point, and whether the blade has planted. */
function swordfallTip(progress: number): { above: number; planted: boolean } {
  if (progress >= SWORDFALL_LAND_PROGRESS) return { above: 0, planted: true };
  const fall = progress / SWORDFALL_LAND_PROGRESS;
  // Accelerating fall — a linear descent reads as a lift, not a drop.
  return { above: SWORDFALL_START_ABOVE * (1 - fall * fall), planted: false };
}

/** The sword itself, tip at (cx, cy - above), pointing down. */
function swordfallBlade(
  ctx: CanvasRenderingContext2D,
  def: VfxDef,
  cx: number,
  cy: number,
  above: number,
  colour: string,
  alpha: number,
): void {
  const tipY = cy - above;
  const guardY = tipY - SWORDFALL_BLADE_LEN;

  ctx.globalAlpha = alpha;
  ctx.fillStyle = colour;

  // Blade: a tapered quad from the point up to the guard.
  ctx.beginPath();
  ctx.moveTo(cx, tipY);
  ctx.lineTo(cx + SWORDFALL_BLADE_HALF_W, guardY);
  ctx.lineTo(cx - SWORDFALL_BLADE_HALF_W, guardY);
  ctx.closePath();
  ctx.fill();

  // Crossguard.
  ctx.fillRect(
    cx - SWORDFALL_GUARD_HALF_W,
    guardY - SWORDFALL_GUARD_H,
    SWORDFALL_GUARD_HALF_W * 2,
    SWORDFALL_GUARD_H,
  );

  // Grip.
  ctx.fillRect(
    cx - SWORDFALL_GRIP_HALF_W,
    guardY - SWORDFALL_GUARD_H - SWORDFALL_GRIP_H,
    SWORDFALL_GRIP_HALF_W * 2,
    SWORDFALL_GRIP_H,
  );

  // Pommel.
  ctx.beginPath();
  ctx.arc(
    cx,
    guardY - SWORDFALL_GUARD_H - SWORDFALL_GRIP_H - SWORDFALL_POMMEL_R,
    SWORDFALL_POMMEL_R,
    0,
    Math.PI * 2,
  );
  ctx.fill();

  ctx.globalAlpha = 1;
}

function drawSwordfallBehind(
  ctx: CanvasRenderingContext2D,
  progress: number,
  def: VfxDef,
  cx: number,
  cy: number,
): void {
  const { planted } = swordfallTip(progress);
  if (!planted) return;

  // Dust wedge kicked up behind the impact. An empty `behind` frame before
  // the blade lands is CORRECT — there is nothing behind the character yet.
  // Do not "fix" it by painting something on the descent frames; the same
  // conclusion rockfall's third landing reached.
  const age = (progress - SWORDFALL_LAND_PROGRESS) / (1 - SWORDFALL_LAND_PROGRESS);
  const spread = 14 + age * 22;
  ctx.globalAlpha = 0.55 * (1 - age);
  ctx.fillStyle = base(def);
  ctx.beginPath();
  ctx.moveTo(cx - spread, cy);
  ctx.lineTo(cx + spread, cy);
  ctx.lineTo(cx + spread * 0.4, cy - 20 - age * 14);
  ctx.lineTo(cx - spread * 0.4, cy - 20 - age * 14);
  ctx.closePath();
  ctx.fill();
  ctx.globalAlpha = 1;
}

function drawSwordfallTint(
  ctx: CanvasRenderingContext2D,
  progress: number,
  def: VfxDef,
  cx: number,
  cy: number,
): void {
  // Bloom along the blade. Composited `add` regardless of def.additive, so
  // keep it faint — see SkillBurst's constructor comment.
  const { above } = swordfallTip(progress);
  swordfallBlade(ctx, def, cx, cy, above, rung(def, RAMP_BASE + 1), 0.35);
}

function drawSwordfallFront(
  ctx: CanvasRenderingContext2D,
  progress: number,
  def: VfxDef,
  cx: number,
  cy: number,
): void {
  const { above, planted } = swordfallTip(progress);
  swordfallBlade(ctx, def, cx, cy, above, rung(def, RAMP_BASE + 1), 1);

  if (!planted) return;

  // Impact ring, expanding and fading from the moment of landing.
  const age = (progress - SWORDFALL_LAND_PROGRESS) / (1 - SWORDFALL_LAND_PROGRESS);
  const rx = 12 + age * 26;
  ctx.globalAlpha = 0.9 * (1 - age);
  ctx.strokeStyle = rung(def, RAMP_BASE + 2);
  ctx.lineWidth = 3;
  ctx.beginPath();
  ctx.ellipse(cx, cy, rx, rx * 0.4, 0, 0, Math.PI * 2);
  ctx.stroke();
  ctx.lineWidth = 1;
  ctx.globalAlpha = 1;
}
```
